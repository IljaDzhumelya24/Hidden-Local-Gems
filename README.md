# Hidden Local Gems

A web project exploring lesser-known places through dedicated discovery and route pages.

## Tech stack

HTML · CSS · JavaScript

## Project structure

| Directory | Purpose |
| --- | --- |
| `Ilja Test/Home` | Homepage |
| `Ilja Test/Entdecken` | Discovery pages, including Berlin |
| `Ilja Test/Routen` | Route pages |
| `Ilja Test/Error` | Error pages |

## Run locally

Clone the repository and serve the project with a local static web server, such as the Live Server extension for VS Code. Open `Ilja Test/Home/index.html` through that server.

No root-level npm manifest is currently provided.
